# Supplier Registry

Приложение для проверки доступности абонентских номеров через внешние API поставщиков.

## Технологии

- Java 17
- Spring Boot 3.3
- Spring Framework RestClient
- Maven
- JUnit 5
- Jackson

## Возможности

- Хранение поставщиков в реестре по ID.
- Загрузка конфигурации поставщиков из JSON-файла.
- Возможность передать готовый список поставщиков.
- Проверка доступности номера через HTTP GET.
- Передача API-ключа в заголовке `X-API-Key`.
- Обработка HTTP 404 как результата `false`.
- Проброс остальных HTTP- и сетевых ошибок вызывающему коду.
- Атомарная замена списка поставщиков.

## Конфигурация

Путь к JSON-файлу задаётся в `application.yml`:

```yaml
suppliers:
  file: ./suppliers.json
```

Пример `supplier-registry/suppliers.json`:

```json
[
  {
    "id": "supplier-1",
    "baseUrl": "https://api.supplier1.example",
    "apiKey": "your-api-key"
  }
]
```

## Запуск

```bash
mvn clean test
mvn spring-boot:run
```

## Структура проекта

- `model` — модели поставщика и ответа API.
- `client` — HTTP-клиент для взаимодействия с поставщиками.
- `provider` — загрузка конфигурации из файла.
- `registry` — хранение и управление поставщиками.
- `service` — бизнес-логика проверки доступности.

## Обработка ответов

| Ответ поставщика | Результат |
|---|---|
| HTTP 200, `status: ok` | `true` |
| HTTP 404 | `false` |
| Другие HTTP-ошибки | Исключение |
| Сетевая ошибка | Исключение |

## Тестирование

Для HTTP-тестов используется `MockRestServiceServer`.
Реальные HTTP-запросы не выполняются.
